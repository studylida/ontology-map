# #139 원문 보존형 추출 비교 결과

## 결론

원문 보존 조건은 엄격 통과 37/64(57.8%)로 기존 조건 27/64(42.2%)보다 15.6%p 높았다. 계약 실패를 제외해도 61.7% 대 48.2%였고, 직접 짝비교에서는 원문 보존 조건 우세 11건, 기존 조건 우세 1건, 동률 40건, 계약 실패로 비교 제외 12건이었다.

그러나 두 조건 모두 기사 한 번의 네 원문 단위를 전부 통과한 경우가 0/16이었다. 따라서 원문 보존 문구는 다음 후보로 유지할 근거는 얻었지만 제품 worker, 자동 저장이나 운영 품질을 승인할 근거는 얻지 못했다.

## 관측된 개선과 회귀

- 계약 실패를 제외한 같은 원문 단위 짝비교에서 원문 보존 조건이 11건 개선했고 기존 조건이 더 나은 경우는 1건이었다.
- 개선은 수익률·상반기 수요 조건 보존, 개발 중 상태와 행사 공개 범위, AI 팩토리 목적 결속, 공동 개발 목적·발언 modality, 제품 선행 근거, 비교 제한 보존에서 관측됐다.
- 회귀 1건은 P07의 전략적 협업 조건을 문장에서 빼고 원문 ID로만 남긴 경우였다.
- 원문 보존 조건에서도 선행 대상 원문 누락, 여러 문장에 걸친 발언의 뒤 절 근거 누락, 수치의 적용 조건 누락이 반복됐다.

## 출력 계약과 비용

총 32회 중 29회가 계약을 통과했다. 실패 3회는 각각 잘못된 `performance` 키, 허용되지 않은 `LOCATION`·`DETAIL` dimension, 3,000-token 상한 도달이었다. 실패를 자동 수정하거나 재호출하지 않았고 모두 비용과 실패율에 포함했다.

이번 라운드 비용은 $0.01267030, 이전 사용량·불명확 예약을 합친 누적값은 $0.86442523다.

## 한계와 다음 순서

- 자료는 새 공식 한국어 기사 8건·사건군 8개에서 목적 표집한 32개 원문 단위다. 128개 평가는 조건·반복을 포함한 항목 수이지 독립 표본 수가 아니다.
- 한 명의 검토자가 동결 gold를 보고 조건명만 가린 채 채점했다. 통계적 일반화나 운영 품질을 주장하지 않는다.
- 이 8개 기사는 이제 회귀 자료로 전환한다. 다음 독립 평가는 다른 원문·사건·재게시 계열을 사용한다.
- 다음 단일축 후보는 원문 보존 문구를 유지한 채, 문장 ID와 정확한 slice를 바꾸지 않고 발언·지시어가 이어지는 원문 묶음을 runtime에서 명시하는 방식이다. DB schema는 바꾸지 않는다.
- Flash의 strict Structured Output 지원 여부는 의미 실험과 분리해 소규모로 확인한다. prompt 기반 JSON object만으로는 16회 중 조건별 1~2회의 계약 실패가 발생했다.
- Atomicity 입력 축소와 표 구조 보조 뷰는 이번 결과의 주된 병목이 아니므로 계속 보류한다.
