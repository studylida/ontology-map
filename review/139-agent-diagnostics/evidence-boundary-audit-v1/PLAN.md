# #139 개별 Claim 근거 경계 무호출 감사 계획

현재의 `prompt + 평탄화된 기사 입력 + 최소 출력 schema + 6,000-token` 결합 구성은 품질 후보로 기각한 상태를 유지한다. 최소 출력은 연구용 대조 형식으로만 남긴다.

기존 4개 기사·8개 출력의 384개 Claim과 42개 필수 사실을 모델 호출 없이 감사한다. 기존 gold·review·score와 20/42는 수정하지 않고, 각 Claim의 원문 지원·modality·원자성·선정 및 검토 완료 상태와 필수 사실의 유효 Claim 대응을 별도 버전에 기록한다.

Claim은 자기 `source_ids`만으로 지원돼야 한다. 다른 Claim의 내용·근거를 빌리지 않는다. 확인된 source_document의 발행 주체는 그 회사의 생략 표현을 한정할 수 있지만 다른 회사·인물·제품·사업부의 문맥을 대신하지 않는다. 필수 사실 PASS는 모든 필수 의미를 함께 덮는 유효 Claim 부분집합이 있을 때만 허용한다. M04-F06의 `s20` 충분 근거 교정은 원본 gold와 분리한다.

모델 호출과 API 비용은 0이다. 제품 코드·DB·migration·metadata·fixture·정식 문서·의존성을 변경하지 않는다. 구조 보존 입력 비교는 이번 감사에서 실행하지 않는다.
