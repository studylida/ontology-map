# #139 인접 원문 ID 비교 결과

## 결론

원문 보존 prompt를 고정하고 위치상 인접한 원문 ID 묶음만 추가한 후보는 기각한다. 이 목적 표집 자료에서 대조군의 엄격 PASS는 12/32(37.5%), 인접 ID 조건은 9/32(28.1%)였고, 두 반복 모두 근거 연결 부족이 해결된 기사는 없었다. 원문 보존 지침 자체를 기각한 결과는 아니다.

| 지표 | 대조군 | 인접 ID 조건 |
|---|---:|---:|
| 엄격 PASS | 12/32 (37.5%) | 9/32 (28.1%) |
| PARTIAL | 11/32 | 7/32 |
| 의미·근거 FAIL | 9/32 | 12/32 |
| 계약 오류 영향 단위 | 0/32 | 4/32 |
| 계약 성공 호출 | 8/8 | 7/8 |
| 네 focus 전부 PASS | 1/8 | 0/8 |
| 비용 | $0.00296604 | $0.00284292 |

계약 실패가 없는 28개 직접 짝의 엄격 PASS는 대조군 8개, 인접 조건 9개였다. 그러나 판정 등급의 이동은 인접 조건 우세 2개, 대조군 우세 4개, 동률 22개였다. 인접 조건의 개선은 N01 s21의 modality와 N04 s25의 선행 대상 해소에서 각각 한 번 나타났다. 반대로 N02 s31의 두 반복과 N03 s25 한 반복에서는 주체나 플랫폼 이름을 풀어 쓰고도 필요한 선행 ID를 연결하지 않아 새 근거 부족이 생겼다.

N01의 곽노정 사장 발언과 N03의 ‘그’·‘이는’ 사례에서는 인접 ID를 제공해도 모델이 필요한 ID를 `context_source_ids`에 넣지 않았다. 따라서 단순한 위치 힌트는 담화 관계를 판정하거나 근거를 연결하는 수단으로 충분하지 않았다. 인접 목록 전체를 복사한 과도한 인용은 관측되지 않았다.

인접 조건 N04 첫 반복은 허용하지 않은 critical-element dimension `RESULT`를 반환해 계약 오류로 보존했다. 재호출하거나 수정하지 않았으며, 나머지 고정 호출은 계획대로 계속했다.

## Strict Structured Output 호환성

의미 비교와 분리한 싱가포르 `qwen3.7-flash-2026-07-15` 시험에서 작은 합성 JSON Schema와 실제 Selection schema의 축소 입력이 모두 API 수용·정상 종료·로컬 Pydantic 검증을 통과했다. 2회 비용은 $0.00015395다. 이는 해당 model·region·schema 조합의 제한적 호환성 증거이며 의미 정확성이나 운영 안정성 증거는 아니다.

## 비용과 범위

의미 비교 비용은 $0.00580896, strict probe를 포함한 이번 추가 비용은 $0.00596291이며, 이전 기록을 포함한 누적 추정값은 $0.87038814/$1이다. 네 공식 한국어 기사에서 미리 정한 16개 원문 단위를 두 조건과 두 반복으로 평가한 결과이며, 64개 판정을 독립 표본으로 해석하지 않는다.

인접 ID 묶음은 시험 중 runtime 정보일 뿐 의미적 의존 관계나 새 Observation이 아니다. 기존 `observation`과 `claim_observation` 계약으로 최종 근거를 표현할 수 있으며 새 DB table·column·task kind는 필요하지 않다. 제품 worker, 자동 저장, 최종 출력 계약과 운영 품질은 승인하지 않는다.
